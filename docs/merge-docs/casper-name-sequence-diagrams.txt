# Admin functions

## Registry admin functions

### Whitelist registrar contract

> As the Registry contract admin, I should be able to whitelist a Registrar contract, so that it can mint new *cspr name 
> tokens in the registry.
> 

```puml
@startuml
'https://plantuml.com/sequence-diagram

'autonumber
actor "Registry Admin"
participant "Registry"
boundary "Events"

== Whitelist registrar contract ==

"Registry Admin" -> "Registry": set_variables(registrars_package_hashes[])
activate "Registry"
Registry -> Registry: Update ACL
Registry -> "Events": VariablesSet event
"Registry" -> "Registry Admin"
deactivate "Registry"

@enduml
```


_used also to delist a registrar_

### Expire domains

> As the registrar contract, I should burn expired tokens in batches upon request.


```puml
@startuml
'https://plantuml.com/sequence-diagram

'autonumber
actor "Anyone"
participant "Registrar"
participant "Registry"
boundary "Events"

== Expire a domain ==

"Anyone" -> "Registrar": expire(cspr_names[])
activate Registrar
loop N times
    Registrar -> Registry: metadata(name_hash)
    Registry -> Registrar
    Registrar -> Registrar: check expiry date
    group expiration + grace_period < blocktime
        Registrar -> Registry: burn(name_hash)
        activate Registry
        Registry -> Registry: clear resolver
        Registry -> "Events": MetadataUpdated event
        Registry -> Registry: burn token
        Registry -> "Events": Burn event
        Registry -> Registrar
        deactivate Registry
    end
end

Registrar -> "Anyone"

@enduml
```

```puml
    Registrar -> Registry: transfer(new_oner, name_hash)
    activate Registry

        Registry ->X "D3 admin": Revert with cannot_transfer error

deactivate Registrar

@enduml
```

# Buy a *cspr name

## Buy with fiat currency

> As a user, I must be able to buy a *cspr name with a fiat currency on D3 web application
 

```puml
@startuml
'https://plantuml.com/sequence-diagram

'autonumber
actor User
participant "d3.app" as d3 #lightblue
participant "Registrar"
participant "Registry"
boundary "Events"

== Buy a *cspr name with fiat currency ==

User -> d3: Buy *cspr name
activate d3
d3 -> d3: process fiat payment
d3 -> User
deactivate d3

d3 -> Registrar: register(TokenizationVoucher)
activate Registrar
Registrar -> Registrar: verify voucher\nexpiration
Registrar -> Registry: metadata(name_hash)
Registry -> Registrar
alt Token exists
    Registrar -> Registrar: check expiration date
    alt expiration+grace_period < blocktime
        Registrar -> Registry: burn(name_hash)
        Registry -> Registry: clear resolver
        Registry -> "Events": MetadataUpdated event
        Registry -> Registry: burn token
        Registry -> "Events": Burn event
    else expiration+grace_period > blocktime
        Registrar ->x d3: Revert with\nnot expired token error
    end
end
Registrar -> Registry: mint(buyer, metadata)
activate Registry
Registry -> Registry: mint token
Registry -> "Events": Mint event
Registry -> Registrar
deactivate Registry
Registrar -> d3
deactivate Registrar
deactivate d3

== ==
@enduml
```

## can_transfer filter

> As the transfer filter contract for the Registry, I should verify token expiration date,
> so that a name token can not be transferred during the renewal grace period.

_The transfer filter contract functionality can be added to the Registrar or to another contract._


```puml

participant "Registry"
participant "Registrar"

activate Registrar
Registrar -> Registry: metadata(name_hash)
Registry -> Registrar: token metadata

 Registrar -> Registry: transfer allowed

 Registrar -> Registry: cannot transfer
end
```
